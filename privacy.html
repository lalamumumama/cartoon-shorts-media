Privacy Policy

Cartoon Shorts Uploader is a private tool used only by its owner. It is not offered to the public and has no other users.

What it accesses

With the owner's consent it uses the YouTube upload permission to publish the owner's own videos to the owner's own channel.

What it stores

Only an OAuth token, kept as a private secret in the owner's own account. No personal data of any other person is collected, stored, shared or sold.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
